Replaces IntelliJ Platform progress bars with animated SVGs featuring Angelina the Mellow Wish (予愿安洁莉娜).

Choose an animation

Broom Ride Delivery Run Diving
  • Choose an animation in Settings > Appearance & Behavior > Angelina Progress Bar.
  • Preview determinate and indeterminate progress bars directly in settings.
  • Adjust motion, transparency, tooltips, and height.
  • HiDPI-aware rendering keeps the SVG artwork crisp and in bounds.

Credits

The code for the progress bar itself was initially adapted from kagof/intellij-pokemon-progress.

This plugin is of course heavily dependent on JetBrains' IntelliJ SDK.
